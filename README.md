# 小小钢琴家

面向零基础儿童的钢琴识谱小游戏，使用 Vue 3、组合式 API 和 Vite，所有源码均为 UTF-8。

## 在线体验

发布后可从 GitHub Pages 打开：`https://<GitHub 用户名>.github.io/piano-sight-game/`。

## 本地运行

使用 Node.js 22.12 或更新版本，进入项目目录执行：

```powershell
npm install
npm run dev
```

访问 `http://localhost:5173/piano/`。同一局域网的手机和平板可以访问 `http://电脑局域网IP:5173/piano/`，实际地址见启动日志。开发服务监听所有网卡。

本项目需要通过开发服务或静态服务器运行，不再直接双击 `index.html`。

```powershell
npm test
npm run build
npm run preview
```

生产文件输出到 `dist/`，预览地址为 `http://localhost:4173/piano/`。本地构建默认使用 `/piano/` 前缀；GitHub Actions 发布时使用 `/piano-sight-game/` 前缀，适配 GitHub Pages 项目站点。

宝藏保存在当前站点的浏览器存储中；旧版 `file://` 页面与新的 HTTP 站点存储独立。

```text

  App.vue                     页面组合与全局按键生命周期
  music.js                    音高、琴键、升降号与出题规则
  composables/usePianoGame.js  响应式游戏状态、计时、音频、奖励
  components/
    GameSettings.vue          顶部练习设置
    PianoKeyboard.vue         琴键、多点触控与音区视图
    StaffScore.vue            大谱表、乐句、临时升降号
    MusicBuddy.vue            小狐狸伙伴
    RewardsDialog.vue         宝藏弹窗
  styles/                     原有主题与手机、平板适配
tests/                        出题、双手配合、乐句、计时与奖励测试
```

## 两种试炼

- 基础识谱：每次完成一组音符，保留原有玩法。
- 乐句试炼：按当前音域、双手组合和升降号设置生成 4、8 或 12 组的短乐句。每行四组，按从左到右的高亮位置作答，长乐句自动换行。答错停留在当前组。
- 可试听当前组或整段；整段试听期间暂停作答与挑战倒计时，切换试炼或重新开始会停止试听。
- 整段完成后显示星级、按组计算的首次正确率和从首次按键起的总用时。自由练习不考核节拍，限时玩法仍使用 60 秒总时间。
- 每行视为一小节；升降号影响本小节同音高后续音符，回到自然音时显示还原号 ♮，换行后重新标记。

## 琴键与练习设置

- 三个八度：C3—B5，共 21 个白键、15 个黑键，黑白键均支持作答和发声。
- 上下两行大谱表：紫色高音谱表对应右手，蓝色低音谱表对应左手。
- 三种组合：右手单音、双手两个音、双手四音和弦；默认双手两个音。
- 两种弹奏方式：逐个找到目标音，或同时按住全部目标琴键。后者支持电脑组合按键和屏幕多点触控。
- 左手快捷键 Z X C V B N M；右手 A S D F G H J；高音扩展 Q W E R T Y U。
- 黑键快捷键按音高从低到高：1 2 3 4 5、6 7 8 9 0、- = [ ] 及反斜杠。
- 升降号可选自然音、升号、降号或混合；非自然音模式每题至少出现一个升降号。升降号标在音符前，独立题目不沿用前题的临时变音。
- 按实际音高判断答案：C♯ 与 D♭ 同键，E♯ 对应 F、F♭ 对应 E。出题排除超出琴键范围的音和同组重复音高。
- 四个音域关卡：每只手三个音、五个音、七个音，以及右手扩展到 C5—E5。
- 自由练习与 60 秒挑战；首个琴键触发计时，奖励弹窗期间暂停计时。
- 一整组全部完成才计分；正确率按整组首次是否无误计算。切换设置会重新开始本轮。
- 小狐狸伙伴、跳跃与彩色音符动画、目标琴键提示、整组试听、连击。
- 累计收集 5、15、30、50 颗星星解锁四份宝藏，自动保存在当前浏览器；重新开始不清除宝藏。

设置栏位于顶部，手机和平板自动分行；默认完整显示全部琴键，无需横向滚动。可切换全部、双手、左手、右手音区放大琴键。双手同时触控时请选择能显示全部目标音的音区；纯鼠标可选择“逐个找到”。

发声需要浏览器支持 Web Audio API，并在首次点击后启用。无需麦克风、账号或网络服务；在线字体不可用时自动使用系统中文字体。
